# Community Editorial Detail

## Goal

공개 Community 상세를 공유 문장과 생각부터 읽고, 이어서 덱 구조를 탐색하는 편집형 읽기 화면으로 개편한다. Community 피드와 Books·Decks에서 확립한 종이색 표면, 명조 본문, 테라코타 강조를 유지한다.

## Scope

- `/community/[postId]`의 상세 헤더, 덱 뷰, 댓글 영역을 개편한다.
- 현재 SSR 데이터 조회, 메타데이터, 공개 접근, 소유자 판별, 댓글 기능을 유지한다.
- API, 응답 타입, 쿼리 키, 라우팅은 변경하지 않는다.

## Page Composition

1. 커뮤니티 복귀 링크와 소유자용 원본 덱 이동
2. 작성자, 작성일, 책 정보
3. 공유 문장, 작성자의 생각, 공유 설명
4. 덱 이름과 모드 전환
5. List 또는 Graph 덱 본문
6. 댓글 작성과 댓글 목록

글 영역은 읽기 폭을 제한하고, 덱 영역은 시각화에 필요한 넓은 폭을 사용한다. 각 영역은 큰 카드 대신 여백과 얇은 구분선으로 나눈다.

## Reading Hierarchy

- 인용문이 있으면 가장 큰 명조체 본문으로 표시한다.
- 생각은 인용문 아래의 보조 본문으로 표시하되 같은 내용이면 중복하지 않는다.
- `caption`과 덱 설명 역시 앞선 내용과 같으면 중복하지 않는다.
- 책 제목과 저자, 덱 이름, 모드는 작은 메타데이터로 둔다.

## Deck Viewer

- 공유 덱의 실제 List·Graph 뷰는 상세에서 유지한다.
- Graph 덱은 기존 Graph/List 전환 기능을 유지한다.
- 전환 컨트롤은 둥근 캡슐 대신 얇은 밑줄 탭으로 표현한다.
- 덱 내용과 상호작용 로직은 변경하지 않고 외곽 레이아웃만 정리한다.

## Comments

- 댓글 작성, 답글, 삭제, 더 보기 동작을 유지한다.
- `Discussion`을 `댓글`로 바꾸고 장식 아이콘과 중첩된 카드 표면을 제거한다.
- 입력 영역과 댓글 목록은 여백과 구분선으로 구분한다.
- 비로그인 사용자의 로그인 이동과 로딩·오류 상태를 유지한다.

## Visual Rules

- 영문 상태 배지, 그라데이션, 큰 그림자, 과도한 둥근 모서리를 제거한다.
- 테라코타는 링크, 선택 상태, 주요 동작에만 사용한다.
- 라이트·다크 모드와 포커스 표시를 유지한다.
- 모바일에서 본문, 메타데이터, 덱 컨트롤이 겹치거나 넘치지 않아야 한다.

## Loading State

상세 스켈레톤은 최종 구조와 같은 순서로 작성자, 본문, 덱, 댓글 영역을 표시한다. 큰 둥근 카드 형태는 사용하지 않는다.

## Verification

- `pnpm typecheck`
- 변경 파일 ESLint
- `pnpm build`
- List·Graph 상세 및 전환 확인
- 로그인·비로그인 댓글 상태 확인
- 데스크톱·모바일, 라이트·다크 모드 확인

## Out Of Scope

- 이전·다음 게시물 API 및 탐색 기능 추가
- 댓글 API 또는 인증 흐름 변경
- 덱 렌더러 내부 동작 변경
- 새로운 라이브러리 추가
