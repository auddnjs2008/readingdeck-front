# 독서 상태 수정 폼 개편

## 목표

책 상세 사이드바의 독서 상태 수정 폼을 짧고 평평한 인라인 편집 영역으로 정리한다.

## 구성

- 폼은 기본 접힘 상태를 유지한다.
- 펼치면 상태 선택을 전체 폭 첫 행에 표시한다.
- 현재 페이지와 전체 페이지를 `현재 / 전체` 형태의 한 행에 배치한다.
- 입력은 둥근 패널 대신 얇은 경계 중심으로 표현한다.
- 저장 버튼은 폼 아래 오른쪽에 배치한다.

## 동작 보존

- 상태, 현재 페이지, 전체 페이지의 로컬 상태 동기화를 유지한다.
- 현재 페이지 0 이상, 전체 페이지 1 이상, 현재 페이지가 전체 페이지를 넘지 않는 검증을 유지한다.
- 저장 mutation, 성공·실패 토스트, 성공 후 접기와 토글 포커스 복귀를 유지한다.
- 책 삭제 기능과 확인 다이얼로그는 변경하지 않는다.

## 접근성

- 토글의 `aria-expanded`와 `aria-controls`를 유지한다.
- 모든 입력은 고유한 레이블 연결을 유지한다.
- 숫자 입력 사이의 `/`는 장식 문자로 처리한다.
- 모바일에서도 두 페이지 입력이 사이드바 폭을 넘지 않아야 한다.
