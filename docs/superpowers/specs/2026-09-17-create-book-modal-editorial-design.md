# 새 책 추가 모달 편집형 개편

## 목표

새 책 추가 흐름을 검색 중심으로 단순화하고, 책 목록·상세·카드 작성 화면과 같은 평평한 편집형 디자인을 적용한다.

## 범위

- 모달을 열면 별도의 방식 선택 화면 없이 책 검색 화면을 먼저 보여준다.
- 직접 입력은 검색 화면에서 전환할 수 있는 보조 경로로 제공한다.
- 검색 API, 선택 데이터 자동 입력, 직접 입력, 표지 업로드, 책 생성 mutation과 성공 이동은 유지한다.
- 독서 상태 등 새로운 입력값은 추가하지 않는다.

## 검색 흐름

1. 모달 제목과 안내
2. 책 제목 검색과 `직접 입력` 전환
3. 검색 결과 목록
4. 선택한 책의 표지·제목·저자·출판사·소개 요약
5. 취소와 `서재에 추가`

검색 결과는 표지만 있는 격자 대신 표지와 핵심 서지정보가 함께 보이는 평평한 행으로 표시한다. 현재 페이지 이동과 검색 상태, 오류 재시도는 유지한다. 결과가 없을 때 직접 입력 경로를 제공한다.

## 직접 입력 흐름

- `검색으로 돌아가기`를 통해 검색 화면으로 복귀할 수 있다.
- 제목, 저자, 출판사, 책 소개, 표지 순서를 유지한다.
- 제목은 필수이며 나머지는 선택이다.
- 입력창과 업로드 영역은 둥근 카드 대신 얇은 경계 중심으로 정리한다.
- 표지가 선택되면 작은 미리보기와 변경 동작을 유지한다.

## 모달 표현

- 제목은 명조 계열, 설명과 필드 레이블은 본문 계열을 사용한다.
- 큰 선택 카드, 과도한 둥근 모서리, 그림자, hover 이동 효과를 제거한다.
- 실제 구현되지 않은 `Esc` 안내는 제거한다.
- 하단 액션은 취소와 등록 버튼만 둔다.
- 모바일과 데스크톱에서 같은 정보 순서를 사용한다.

## 상태와 오류

- 모달을 닫으면 검색어, 선택 결과, 직접 입력값과 표지를 초기화한다.
- 책 제목이 없거나 검색 결과를 선택하지 않은 상태에서는 등록할 수 없다.
- 생성 요청 중에는 중복 제출을 막는다.
- 검색 로딩·빈 결과·오류 상태와 재시도 동작을 유지한다.
- 생성 성공 시 모달을 닫고 생성된 책 상세로 이동한다.
