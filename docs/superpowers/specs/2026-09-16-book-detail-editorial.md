# Book Detail Editorial Design

## Goal

책 상세를 책 정보는 계속 참고하면서 독서 카드를 빠르게 훑고 펼쳐 읽는 편집형 화면으로 개편한다. Books 목록과 카드 상세에서 확립한 종이색 표면, 명조 본문, 테라코타 강조를 이어간다.

## Scope

- `/books/[id]`의 책 사이드바, 카드 헤더·필터·목록, 로딩·빈 상태를 개편한다.
- 기존 책 상세·카드 목록 조회, 필터, 정렬, 무한 스크롤, 카드 생성·삭제, 독서 상태 수정, 책 삭제를 유지한다.
- API, 쿼리 키, 응답 타입, 라우팅은 변경하지 않는다.
- 카드 상세 모달 연결은 이번 범위에 포함하지 않는다.

## Page Layout

- 데스크톱은 왼쪽 고정 책 사이드바와 오른쪽 카드 읽기 영역을 유지한다.
- 모바일은 책 정보가 카드 목록 위에 배치되는 단일 열로 전환한다.
- 전체 배경은 Books와 같은 종이색 라이트·다크 표면을 사용한다.
- 큰 패널과 중첩된 카드 대신 여백과 필요한 구분선으로 영역을 나눈다.

## Book Sidebar

- 책 표지는 원본 비율로 표시하고 배경 블러, 큰 그림자, 과도한 둥근 모서리를 제거한다.
- 제목, 저자, 시작일은 평평한 텍스트 정보로 표시한다.
- 독서 상태, 진행률, 현재·전체 페이지는 요약 형태로 항상 표시한다.
- `독서 상태 수정`을 누를 때만 상태·현재 페이지·전체 페이지 입력 폼을 펼친다.
- 저장, 유효성 검사, 오류 토스트, 책 삭제와 서재 복귀 동작을 유지한다.

## Cards Header And Filter

- `독서 카드`, 현재 불러온 카드 수, 카드 추가 동작을 간결한 헤더에 둔다.
- 장식 문장, Feather 아이콘, 그라데이션, 둥근 패널과 그림자를 제거한다.
- 필터와 정렬은 얇은 툴바로 표현한다.
- 현재 유형, 인용문 여부, 페이지 범위, 정렬 기능과 debounce 동작을 유지한다.

## Card Accordion

- 모든 카드는 제목 유무와 관계없이 처음에 접힌 상태로 표시한다.
- 접힌 행에는 카드 유형, 페이지 범위, 선택적 제목을 표시한다.
- 제목이 없으면 생각을 최대 두 줄까지 미리보기로 표시한다.
- 행을 누르면 같은 위치에서 인용문과 생각 전체를 펼친다.
- 펼친 영역에 카드 삭제 버튼을 유지한다.
- 카드 유형은 한글 텍스트로 표시하고 캡슐 배지, 배경 이미지, 그라데이션, 그림자, hover 이동을 제거한다.
- 카드 간에는 얇은 구분선만 사용한다.

## Loading, Empty, And Pagination

- 카드 로딩은 최종 아코디언 행과 같은 평평한 스켈레톤으로 표시한다.
- 빈 상태는 큰 점선 카드와 장식 아이콘 대신 짧은 문장과 구분선으로 표시한다.
- 다음 페이지 로딩은 기존 카드를 유지하고 목록 아래에만 작은 진행 상태를 표시한다.
- IntersectionObserver 기반 무한 스크롤 동작을 유지한다.

## Accessibility And Responsive Behavior

- 카드 행은 `button`을 유지하고 `aria-expanded`로 상태를 전달한다.
- 독서 상태 수정 토글과 삭제 동작은 키보드로 접근 가능해야 한다.
- 긴 제목과 생각은 모바일과 데스크톱에서 가로로 넘치지 않아야 한다.
- 라이트·다크 모드에서 본문, 보조 글자, 구분선 대비를 유지한다.
- sticky 사이드바가 모바일에서 콘텐츠를 가리거나 화면 높이를 강제하지 않아야 한다.

## Verification

- `pnpm typecheck`
- 변경 파일 ESLint
- `pnpm build`
- 제목 있음·없음 카드의 동일한 접기·펼치기 확인
- 인용문 있음·없음 카드 확인
- 필터, 정렬, 페이지 범위와 무한 스크롤 확인
- 독서 상태 폼 열기·저장·유효성 검사 확인
- 카드·책 삭제 확인
- 모바일·데스크톱과 라이트·다크 모드 확인

## Out Of Scope

- 카드 클릭 시 상세 모달 열기
- 책 또는 카드 API 변경
- 카드 수정 기능 추가
- 새로운 UI 라이브러리 추가
