# 로그인 화면 편집형 개편

## 목표

ReadingDeck의 따뜻한 색과 독서 서비스의 성격은 유지하면서, 현재 로그인 화면의 장식적인 배경과 일반적인 인증 카드 인상을 걷어낸다. 사용자가 인증 수단을 바로 이해하고 선택할 수 있는 조용한 단일 열 화면으로 정리한다.

## 범위

- `LoginPageClient`의 문구와 레이아웃, 스타일만 변경한다.
- 카카오와 Google 로그인 버튼 및 현재 인증 URL 이동 방식은 유지한다.
- 이용약관과 개인정보처리방침 링크를 유지한다.
- 새로운 이미지, 컴포넌트, 상태, 의존성은 추가하지 않는다.
- 동작이 정의되지 않은 `로그인에 문제가 있나요?` 버튼은 제거한다.

## 구성

화면은 카드로 감싸지 않은 하나의 세로 흐름을 사용한다.

1. 상단 ReadingDeck 브랜드
2. 서비스 성격을 나타내는 작은 레이블
3. `읽고 남긴 생각을 이어가세요.` 제목
4. 문장과 생각을 계속 기록한다는 짧은 설명
5. 카카오 로그인 버튼
6. Google 로그인 버튼
7. 이용약관과 개인정보처리방침 안내
8. 하단의 짧은 ReadingDeck 설명

## 시각 방향

- 전체 배경은 기존 `background` 토큰을 사용하며 그라데이션과 장식 효과를 제거한다.
- 제목은 `font-serif`를 사용해 다른 편집형 화면과 연결한다.
- 로고는 과한 둥근 배경이나 그림자 없이 브랜드 이름과 함께 표시한다.
- 로그인 영역은 테두리 카드로 감싸지 않고 여백과 글자 크기로 위계를 만든다.
- 카카오 버튼은 서비스 고유 색을 유지한다.
- Google 버튼은 얇은 테두리의 보조 액션으로 표시한다.
- 데스크톱에서도 읽기 폭을 좁게 유지하고, 모바일에서는 동일한 순서로 자연스럽게 축소한다.

## 동작 보존

- 카카오 선택 시 `${NEXT_PUBLIC_API_BASE_URL}/auth/kakao`로 이동한다.
- Google 선택 시 `${NEXT_PUBLIC_API_BASE_URL}/auth/google`로 이동한다.
- 별도 로딩 상태나 오류 처리는 추가하지 않는다. OAuth 진입은 현재처럼 브라우저 전체 이동으로 처리한다.

## 접근성과 검증

- 인증 액션은 키보드로 사용할 수 있는 버튼을 유지한다.
- 공급자 아이콘은 장식 요소로 처리한다.
- 포커스 표시와 충분한 텍스트 대비를 유지한다.
- 변경 파일 ESLint, TypeScript 검사, 프로덕션 빌드로 검증한다.
- 데스크톱과 모바일에서 텍스트 줄바꿈, 버튼 폭, 세로 여백을 확인한다.
