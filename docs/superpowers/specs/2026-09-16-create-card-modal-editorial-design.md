# 카드 추가 모달 편집형 개편

## 목표

책 상세 화면의 평평한 편집형 디자인과 카드 작성 모달을 연결한다. 기존 카드 생성 동작은 유지하고, 입력 순서와 시각적 위계만 단순하게 정리한다.

## 범위

- `CreateCardModal`의 레이아웃과 스타일을 변경한다.
- 카드 유형, 제목, 원문, 페이지, 내 생각의 필드와 순서는 유지한다.
- API payload, mutation, 임시 저장, 유효성 검사, 성공·실패 처리는 유지한다.
- 카드 유형이나 작성 필드의 기능은 추가하지 않는다.

## 구성

모달은 하나의 세로 작성 흐름을 사용한다.

1. 제목과 짧은 안내
2. 카드 유형 선택
3. 선택 제목
4. 선택 원문 인용
5. 선택 페이지 범위
6. 필수 내 생각
7. 임시 저장 안내
8. 취소와 저장 액션

데스크톱에서도 별도 사이드 레일이나 다단 작성 화면을 만들지 않는다. 모바일과 데스크톱이 같은 읽기 순서를 공유한다.

## 카드 유형

- 유형은 탭이 아니라 단일 선택 라디오 그룹으로 구현한다.
- 선택지는 `인사이트`, `변화`, `행동`, `질문`으로 표시한다.
- 선택 상태는 배경 변화와 작은 강조 표시로 구분한다.
- 선택한 유형의 설명을 그룹 아래에 표시한다.
- 데스크톱에서는 4열, 좁은 화면에서는 2열로 배치한다.
- 기존 API 값 매핑은 변경하지 않는다.

## 입력 스타일

- 제목과 페이지 입력은 둥근 카드 대신 얇은 경계 중심의 평평한 필드로 표시한다.
- 원문 인용은 세로 강조선과 명조 계열 본문으로 인용 영역임을 드러낸다.
- 내 생각은 원문보다 넓고 강한 본문 영역으로 표시한다.
- 선택·필수 여부는 각 레이블 옆의 보조 문구로 표시한다.
- 큰 컬러 카드, 유형별 다색 배경, 그림자, 위로 움직이는 hover 효과는 사용하지 않는다.

## 동작 보존

- 모달을 다시 열면 해당 책의 `sessionStorage` 초안을 복원한다.
- 생각은 3자 이상이어야 한다.
- 시작 페이지가 끝 페이지보다 클 수 없다.
- 저장 요청 전 모달을 닫고 폼을 초기화하는 현재 흐름을 유지한다.
- 저장 실패 시 제출 초안을 복원하고 모달을 다시 연다.
- 저장 성공 시 초안을 제거하고 `방금 카드 보기` 액션을 제공한다.
- 저장 중 중복 제출을 막는다.

## 접근성과 반응형

- 유형 선택은 키보드로 조작 가능한 라디오 그룹 의미를 제공한다.
- 모든 입력은 연결된 레이블 또는 접근 가능한 이름을 가진다.
- 모달 내부 스크롤과 닫기 버튼, 포커스 트랩은 기존 Dialog 동작을 사용한다.
- 좁은 화면에서도 저장 액션과 입력 내용이 잘리지 않아야 한다.
- 화면에 표시하는 단축키 안내는 실제 구현된 동작만 남긴다.
