# 랜딩과 서비스 홈 진입 분리

사용자가 승인한 범위: 별도 피처 브랜치에서 랜딩 내비게이션과 서비스 메뉴를 분리하고 홈을 정리한다. 자동 리다이렉트와 사이드바는 추가하지 않는다.

- 기존 종이색·명조/고딕·테라코타 강조색을 유지한다. 섹션 사이 여백과 구분선으로 위계를 표현한다.
- 랜딩은 소개 → 사용 방법 → 연결 예시 → 시작하기 구성. 소개/사용 방법 메뉴는 페이지 내 앵커이며 공개 덱은 서비스로 이동한다.
- 로그인 전에는 로그인/시작하기, 로그인 후에는 내 기록으로(`/books`)를 표시한다. 모바일 랜딩에는 소개 메뉴를 상단 두 번째 줄로 두고 앱 하단 메뉴는 표시하지 않는다.
- 서비스 메뉴는 홈(`/books`), 내 서재(`/books/library`), 내 덱, 공개 덱이다. 로고를 통해 서비스 소개로 돌아간다.
- 홈은 오늘의 카드 → 읽는 책·작성 중인 덱 → 최근 기록한 책 → 덱 제안 순서다. 덱은 기존 API에서 최근 수정 초안 3개를 조회한다. 신규 사용자에게는 첫 책 추가 안내를 유지한다.
- 기존 랜딩 등장 효과, 모션 축소 설정을 따르는 앵커 스크롤, 링크 hover 피드백을 사용한다.
- 검증: 로그인 전후 진입, 모바일 헤더와 하단 메뉴, 앵커 가림, 초안 성공/빈 목록/실패, 신규 사용자, 기존 반응·연결·스크롤 회귀.

## 로컬 확인

`pnpm dev:local` 실행 후 `/`에서 소개 메뉴와 로그인 상태별 진입 버튼을, `/books`에서 홈·내 서재 메뉴 분리와 작성 중인 덱을 확인한다. 두 URL은 그대로 유지한다. 최근 기록한 책은 간단한 목록으로 표시한다.

브라우저 검증은 사용자 데이터를 변경하지 않고 HTTP 응답을 모킹한다.

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node scripts/browser/entry-navigation-check.mjs
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node scripts/browser/reflection-check.mjs
```
