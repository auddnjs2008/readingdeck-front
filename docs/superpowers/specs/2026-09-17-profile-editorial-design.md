# 프로필 화면 편집형 개편

## 목표

프로필을 SNS형 인물 소개나 설정 대시보드가 아니라, ReadingDeck에서 쌓은 개인 독서 기록의 요약으로 보여준다. 기존의 큰 아바타와 둥근 통계 카드를 걷어내고 사용자 정보, 기록 수, 계정 메뉴가 한 흐름으로 읽히게 한다.

## 범위

- `/profile`의 레이아웃, 문구, 로딩 화면을 변경한다.
- 페이지 메타 제목을 전역 제목 템플릿에 맞는 `프로필`로 정리한다.
- 프로필 수정 다이얼로그와 회원 탈퇴 영역의 시각 스타일을 같은 편집형 톤으로 맞춘다.
- 프로필 및 서재 통계 조회, 수정 mutation, 탈퇴 mutation과 오류 처리는 유지한다.
- 새로운 API, 상태, 컴포넌트, 의존성은 추가하지 않는다.

## 페이지 구성

### 1. 머리말

- 작은 레이블 `MY PROFILE`을 표시한다.
- 제목은 `나의 기록`으로 한다.
- 설명은 `ReadingDeck에서 쌓아온 독서 기록과 계정을 관리합니다.`로 한다.

### 2. 사용자 정보

- 아바타, 이름, 이메일, `프로필 수정` 액션을 한 행에 표시한다.
- 아바타는 이름과 기록보다 강하게 보이지 않도록 현재보다 작게 줄인다.
- 모바일에서는 수정 액션이 사용자 정보 아래로 내려간다.
- 사용자 정보 영역은 카드나 그림자 없이 아래 구분선으로만 나눈다.

### 3. 기록 요약

- `bookCount`는 `서재에 담긴 책`으로 표시한다.
- `cardCount`는 `남긴 생각 카드`로 표시한다.
- 두 수치는 큰 명조 숫자와 짧은 한글 레이블로 구성한다.
- 둥근 카드와 장식 아이콘을 사용하지 않고, 하나의 가로 지면을 얇은 구분선으로 나눈다.
- 모바일에서는 세로로 쌓는다.

### 4. 계정과 지원

- 고객지원, 개인정보처리방침, 이용약관을 각각 한 행의 링크로 표시한다.
- 회원 탈퇴는 목록의 마지막 행에 배치하고 위험 색상으로만 구분한다.
- 탈퇴 설명은 확인 다이얼로그 안에서 제공하므로 페이지에 반복하지 않는다.
- 회원 탈퇴 클릭 시 기존 확인 다이얼로그를 연다.

## 프로필 수정 다이얼로그

- 이름, 이미지 선택, 유효성 검사와 저장 동작은 유지한다.
- 큰 둥근 모서리, 강한 그림자, 캡슐형 이미지 변경 버튼을 줄인다.
- 아바타와 이미지 입력 설명, 닉네임 입력을 한 세로 흐름으로 구성한다.
- 저장 버튼과 저장 즉시 반영된다는 안내를 유지한다.
- 닫을 때 임시 이름과 선택 이미지를 초기화하는 현재 동작을 유지한다.

## 회원 탈퇴 다이얼로그

- 삭제 경고, mutation, 성공·실패 토스트와 `/login` 이동을 유지한다.
- 프로필 수정 다이얼로그와 같은 평평한 모서리와 간격을 사용한다.
- 파괴적 액션은 기존 색상과 비활성 상태를 유지한다.

## 로딩과 오류

- 조회 실패 시 기존 `QueryError`와 재시도 동작을 유지한다.
- 로딩 화면은 머리말, 사용자 정보, 기록 수, 계정 목록과 같은 위치에 스켈레톤을 표시한다.
- 스켈레톤은 큰 둥근 카드 없이 선과 직사각형 블록으로 구성한다.

## 반응형과 접근성

- 페이지 최대 폭은 현재 본문 폭을 유지한다.
- 긴 이메일은 사용자 정보 영역을 넘지 않도록 줄바꿈한다.
- 링크와 버튼의 키보드 포커스 표시를 유지한다.
- 위험 액션은 색상뿐 아니라 `회원 탈퇴` 문구로도 의미가 전달되어야 한다.
- 기존 Dialog의 포커스 트랩, 닫기 버튼과 접근 가능한 제목을 유지한다.
