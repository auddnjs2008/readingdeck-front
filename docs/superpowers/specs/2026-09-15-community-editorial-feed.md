# Community Editorial Feed

## Goal

공개 Community 목록을 공유된 문장과 생각이 먼저 읽히는 편집형 피드로 개편한다. Books와 Decks에서 확립한 ReadingDeck의 종이색 표면, 명조 제목, 테라코타 강조를 유지한다.

## Visual Thesis

다른 독자의 문장과 생각을 천천히 펼쳐 읽는 공개 독서 지면. 장식용 카드와 덱 구조 미리보기보다 글의 내용과 작성자를 중심에 둔다.

## Scope

- `/community` 목록 화면과 피드 항목의 배치 및 시각 표현을 개편한다.
- 현재 SSR React Query hydration, 무한 스크롤, 상세 이동을 유지한다.
- API, 쿼리 키, 응답 타입, 라우팅은 변경하지 않는다.
- Community 상세 화면과 댓글 화면은 변경하지 않는다.

## Page Composition

- 배경의 그라데이션과 점무늬를 제거하고 Books·Decks와 같은 라이트·다크 표면을 사용한다.
- 상단에는 `커뮤니티` 제목, 짧은 설명, 공유된 덱 수와 최근 갱신일을 표시한다.
- 최신 게시물 한 개는 전체 폭으로 크게 표시한다.
- 나머지 게시물은 데스크톱 2열, 모바일 1열로 배치한다.
- Masonry columns를 제거해 읽는 순서가 왼쪽에서 오른쪽, 위에서 아래로 고정되게 한다.
- 게시물은 둥근 카드로 감싸지 않고 여백과 얇은 하단선으로 구분한다.

## Post Hierarchy

1. 작성자 프로필, 이름, 작성일
2. 공유한 인용문 또는 생각
3. 작성자의 생각과 설명문
4. 책 제목
5. 덱 이름, 모드, 규모
6. `덱 읽기` 이동

인용문이 있으면 인용문을 가장 크게 표시하고 생각을 그 아래에 둔다. 인용문이 없으면 생각 자체를 큰 명조체로 표시한다. `caption`은 보조 본문으로 둔다. 최신 게시물은 같은 데이터 구조를 사용하되 글자 크기와 여백만 키운다.

## Removed From Feed

- 그래프 미리보기
- 카드 목록 미리보기
- 덱 모드 배지
- 장식용 인용 아이콘
- 그라데이션과 큰 그림자
- 큰 모서리와 hover 이동 효과

그래프와 카드의 실제 구조는 Community 상세 화면에서만 보여준다.

## Deck Metadata

- 피드 하단에는 책 제목과 덱 이름을 표시한다.
- 덱 모드는 `List` 또는 `Graph` 텍스트로 표시한다.
- List 덱은 카드 수, Graph 덱은 노드 수를 표시한다.
- 메타데이터는 작은 고딕체로 표시하고 테라코타는 이동 행동과 제한적인 강조에만 사용한다.

## Interaction And Accessibility

- 게시물 전체를 기존 Community 상세 경로로 연결한다.
- 링크는 포인터와 키보드로 모두 접근 가능해야 한다.
- 작성자 이름과 긴 문장, 덱 이름이 컨테이너를 넘지 않아야 한다.
- 콘텐츠 이해에 필요하지 않은 진입 애니메이션은 제거한다.
- 포커스 표시와 모바일 터치 영역은 기존 수준 이상을 유지한다.

## Loading, Error, And Empty States

- 최초 로딩은 최종 게시물 지면과 비슷한 텍스트형 스켈레톤으로 표시한다.
- 다음 페이지를 불러올 때는 기존 게시물을 유지하고 목록 아래에만 작은 진행 상태를 표시한다.
- 오류와 빈 상태는 큰 둥근 컨테이너 없이 구분선과 짧은 문장으로 표시한다.
- 게시물이 하나뿐이면 전체 폭 최신 게시물만 표시한다.
- 무한 스크롤의 종료 안내와 IntersectionObserver 동작은 유지한다.

## Verification

- `pnpm typecheck`
- `pnpm lint`
- `pnpm build`
- SSR HTML과 hydration 후 목록 내용 확인
- 데스크톱과 모바일에서 1개, 2개 이상, 긴 문장 데이터 확인
- 라이트와 다크 모드에서 대비, 오버플로, 포커스 확인
- 상세 이동과 무한 스크롤 확인

## Out Of Scope

- Community 상세와 댓글 UI 개편
- 피드 정렬 및 검색 기능 추가
- 추천 알고리즘이나 반응 기능 추가
- 인증 또는 서버 API 변경
- 새로운 UI 및 애니메이션 라이브러리 도입
