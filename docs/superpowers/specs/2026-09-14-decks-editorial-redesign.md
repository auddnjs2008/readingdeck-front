# Decks Editorial Redesign

## Goal

Books에서 확립한 조용한 편집 디자인을 `/decks` 목록으로 확장한다. 완성된 덱의 그래프 미리보기를 페이지의 주 콘텐츠로 두고, 작성 중인 덱은 빠르게 작업을 재개하는 보조 영역으로 정리한다.

## Visual Thesis

완성된 생각의 연결을 차분하게 펼쳐 보는 아카이브. 종이색 배경과 명조 제목, 얇은 구분선을 유지하고 테라코타는 주요 행동과 현재 상태에만 사용한다.

## Scope

- `/decks` 목록 화면의 배치와 시각 표현을 개편한다.
- 기존 검색, 필터, 정렬, 덱 이동, 새 덱 생성 기능을 유지한다.
- API, React Query, 라우팅, 데이터 타입은 변경하지 않는다.
- 덱 상세, 읽기 화면, 생성 및 편집기는 변경하지 않는다.

## Content Hierarchy

1. 페이지 제목과 새 덱 만들기
2. 이어 쓰기
3. 완성된 덱

`이어 쓰기`는 작성 중인 덱을 빠르게 찾는 얇은 가로 목록이다. `완성된 덱`은 그래프 미리보기가 중심인 3열 편집형 그리드로 구성한다. 모바일에서는 두 영역 모두 한 열로 쌓는다.

## Typography And Surface

- 페이지와 덱 제목은 `Noto Serif KR`을 사용한다.
- 설명, 상태, 노드 수, 연결 수, 수정 시각은 `Noto Sans KR`을 사용한다.
- 큰 곡률, 강한 그림자, 배경 무늬, 장식 아이콘을 제거한다.
- 섹션은 별도 카드로 감싸지 않고 얇은 구분선과 여백으로 나눈다.
- 그래프 미리보기에는 얇은 테두리와 최대 4px 모서리를 허용한다.
- Books에서 사용하는 종이색, 잉크색, 테라코타와 다크 모드 색상을 그대로 사용한다.

## Page Header

페이지 제목과 설명을 왼쪽에 두고 `새 덱 만들기`를 오른쪽의 테라코타 주요 버튼으로 배치한다. 헤더 아래에는 얇은 구분선을 둔다. 모바일에서는 제목 아래에 버튼을 배치한다.

## Continue Writing

- 기존 `작업 중인 덱`을 `이어 쓰기`로 표시한다.
- 큰 카드와 캐러셀 장식을 제거하고 제목, 노드 수, 수정 시각을 한 줄 항목으로 표시한다.
- 항목 전체를 선택하면 기존 덱 목적지로 이동한다.
- 새 덱 만들기는 페이지 헤더가 담당하며 이 영역에 중복 생성 카드를 두지 않는다.
- 서재에 책이 없을 때는 책 추가 안내와 편집 화면 진입 링크를 간결하게 유지한다.

## Completed Decks

- 저장된 덱 중 발행된 덱의 시각적 비중을 높인다.
- 각 항목은 그래프 미리보기, 덱 제목, 노드 수, 연결 수, 수정 시각을 표시한다.
- 상태와 공유 여부는 여러 색상의 채운 배지 대신 짧은 텍스트로 표현한다.
- 데스크톱은 3열, 태블릿은 2열, 모바일은 1열 그리드를 사용한다.
- 항목 전체를 선택하면 `getDeckHref`가 반환한 기존 목적지로 이동한다.

## Search And Filters

- 검색 입력은 밑줄형으로 단순화한다.
- 상태, 모드, 공유 필터와 최신순·오래된순 정렬 기능은 유지한다.
- 기본 상태 필터와 초기화 기준은 `발행됨`으로 설정해 `이어 쓰기`의 초안과 중복되지 않게 한다.
- 필터는 둥근 칩 묶음 대신 작은 세그먼트 컨트롤로 표시한다.
- 활성 항목에만 테라코타와 굵기 차이를 사용한다.
- 필터 조합이 만드는 서버 요청 조건은 변경하지 않는다.

## States And Accessibility

- 로딩 상태는 실제 목록과 같은 크기의 평평한 스켈레톤을 사용한다.
- 빈 상태는 큰 점선 컨테이너 없이 안내 문장과 필요한 링크만 표시한다.
- 오류 상태는 구분선과 오류 텍스트로 표시한다.
- 클릭 가능한 덱 항목은 키보드로 진입할 수 있어야 한다.
- 포커스 표시와 터치 영역은 기존 접근성 수준 이상을 유지한다.
- 불필요한 모션은 추가하지 않고 기존 이동 효과도 줄인다.

## Verification

- `pnpm typecheck`
- `pnpm lint`
- 관련 테스트
- 데스크톱과 모바일에서 목록, 빈 상태, 로딩 상태 확인
- 라이트와 다크 모드에서 대비, 오버플로, 텍스트 겹침 확인
- 검색, 필터, 정렬, 초안 이어 쓰기, 새 덱 생성, 덱 진입 확인

## Out Of Scope

- 덱 상세와 공개 읽기 화면 개편
- 덱 생성 및 편집기 개편
- 인증이나 데이터 요청 변경
- 새로운 UI 또는 애니메이션 라이브러리 도입
- 새로운 공통 디자인 시스템 추상화
