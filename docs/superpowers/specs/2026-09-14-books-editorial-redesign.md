# Books Editorial Redesign

## Goal

ReadingDeck의 따뜻한 독서 서비스 정체성은 유지하면서 Books 메인에서 AI 템플릿처럼 보이는 장식을 걷어낸다. `typing.works`의 절제된 인상을 참고하되, 흑백 복제가 아니라 책 표지와 읽는 문장이 중심인 편집 디자인을 만든다.

## Visual Thesis

옅은 종이 위에 책과 문장을 정돈한 조용한 편집 지면. 테라코타는 현재 위치와 주요 행동에만 사용하고, 표지 색상이 화면의 시각적 다양성을 담당한다.

## Scope

- Books 메인의 콘텐츠 순서와 기능은 유지한다.
- 공통 글꼴을 정리하고, 색상과 모서리 규칙은 Books 메인 범위에서 라이트·다크 모드에 맞게 적용한다.
- API, React Query, 라우팅, 데이터 구조는 변경하지 않는다.
- 첫 적용은 Books 메인으로 제한하며 다른 페이지 개편은 후속 작업으로 둔다.

## Content Hierarchy

1. 오늘의 카드 스택
2. 지금 읽는 책
3. 최근 기록한 책
4. 덱으로 묶어볼 카드

오늘의 카드 스택은 페이지의 주인공으로 유지한다. 한 장의 기록을 넓은 지면처럼 보여주고, 인용문과 책 정보를 두 열로 구성한다. 나머지 영역은 별도의 떠 있는 컨테이너 없이 얇은 구분선으로 연결한다.

## Typography

- `Noto Sans KR`: 탐색, 설명, 버튼, 메타데이터
- `Noto Serif KR`: 페이지 제목, 책 제목, 카드 인용문
- 글꼴은 두 종류로 제한한다.
- 영문 대문자 라벨은 짧은 보조 정보에만 사용한다.
- 과도한 자간과 뷰포트 기반 글자 크기는 사용하지 않는다.

## Color And Surface

### Light

- Paper: `#F9F8F4`
- Ink: `#292724`
- Terracotta: `#A45138`
- Book green: `#345047`
- Divider: `#D8D4CC`

### Dark

- Background: `#242320`
- Foreground: `#EBE7DF`
- Terracotta: `#D77B5E`
- Divider: `#4B4842`
- 푸른 슬레이트, 발광 효과, 반투명 유리 효과는 사용하지 않는다.

테라코타는 주요 행동과 현재 탐색 위치에만 사용한다. 녹색은 책 표지나 제한적인 상태 표현에만 사용하며, 상태 표현이 필요하지 않은 영역에 장식으로 추가하지 않는다.

## Components

### Page Header

현재 내비게이션 구조를 유지한다. 활성 메뉴만 테라코타로 표시하고, 헤더 아래에는 얇은 구분선을 둔다.

### Daily Stack

큰 둥근 카드와 강한 그림자를 제거한다. 인용문, 생각, 책 표지와 메타데이터를 하나의 평평한 구성으로 배치한다. 이전·다음 탐색은 4px 모서리의 아이콘 버튼으로 제공한다.

### Book Lists

책 표지를 중심으로 4열 그리드를 사용하고 모바일에서는 2열로 줄인다. 제목, 저자, 활동 정보만 표시하며 개별 항목을 장식용 카드 컨테이너로 감싸지 않는다.

### Deck Suggestion

30px 모서리, 중첩 카드, 그라데이션, 큰 그림자, AI 아이콘과 다색 배지를 제거한다. 책 제목, 카드 수, 한 문장 안내, `초안 덱 만들기` 행동을 한 줄 제안으로 구성하고 모바일에서는 세로로 쌓는다.

### Controls

- 주요 행동: 테라코타 채움 버튼
- 보조 행동: 얇은 외곽선 버튼
- 이동: 텍스트 링크 또는 익숙한 아이콘 버튼
- 모서리: 기본 4px, 콘텐츠 컨테이너는 최대 8px
- 책 표지에만 작은 물리적 그림자를 허용한다.

## States And Accessibility

- 로딩, 빈 상태, 오류 상태의 기존 동작과 문구는 유지한다.
- 빈 상태에서도 큰 점선 카드와 장식 아이콘을 줄이고 텍스트와 행동을 명확히 배치한다.
- 라이트·다크 모드 모두 텍스트와 구분선 대비를 확인한다.
- 키보드 포커스, 버튼 레이블, 터치 영역은 기존 접근성 수준 이상을 유지한다.
- `prefers-reduced-motion`을 존중하고, 콘텐츠 이해에 필요하지 않은 애니메이션은 추가하지 않는다.

## Verification

- `pnpm lint`
- `pnpm typecheck`
- 관련 테스트
- 데스크톱과 모바일에서 Books 메인 스크린샷 비교
- 라이트·다크 모드에서 오버플로, 텍스트 겹침, 대비 확인
- 기존 책 이동, 카드 열기, 책 추가, 덱 생성 동작 확인

## Out Of Scope

- 다른 페이지의 전면 개편
- 데이터 요청이나 인증 흐름 변경
- 새 UI 라이브러리 또는 애니메이션 라이브러리 도입
- 새로운 디자인 시스템 추상화
