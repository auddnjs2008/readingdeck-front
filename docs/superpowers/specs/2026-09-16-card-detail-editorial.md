# Card Detail Editorial Design

## Goal

카드 상세 페이지와 모달을 생각을 가장 먼저 읽는 편집형 지면으로 통일한다. Books, Decks, Community에서 확립한 종이색 표면, 명조 본문, 테라코타 강조를 이어간다.

## Scope

- 독립 카드 상세 `/cards/[cardId]`와 인터셉트 모달 `/(.)cards/[cardId]`을 함께 개편한다.
- 두 화면은 같은 콘텐츠 순서와 시각 위계를 사용하고, 모달은 글자 크기와 여백만 압축한다.
- 기존 카드 조회, 오류 재시도, 모달 닫기, 책 상세 이동을 유지한다.
- API, 쿼리 키, 라우팅, 응답 타입은 변경하지 않는다.

## Reading Order

1. 카드 유형과 페이지 범위
2. 선택적인 카드 제목
3. 카드에 기록한 생각
4. 원문 인용
5. 책 제목, 저자, 출판사, 저장일, 다시 본 횟수
6. 책 상세 이동

생각은 가장 큰 명조체 본문으로 표시한다. 인용문은 생각 아래에 얇은 왼쪽선과 작은 `원문 인용` 라벨로 구분한다. 인용문이 없으면 해당 영역을 렌더링하지 않는다.

## Labels

- `Insight`는 `인사이트`
- `Change`는 `변화`
- `Action`은 `행동`
- `Question`은 `질문`
- `Original Quote`는 `원문 인용`

카드 유형은 캡슐 배지가 아니라 작은 테라코타 텍스트로 표시한다. 카드 제목은 존재할 때만 보조 제목으로 표시한다.

## Standalone Page

- 최대 읽기 폭은 현재처럼 `900px` 안에서 유지한다.
- 큰 둥근 카드, 그라데이션 장식, 큰 그림자를 제거한다.
- 배경 위에 평평한 본문을 배치하고 영역은 여백과 필요한 구분선으로 나눈다.
- 상단 `책 페이지로` 복귀 링크와 하단 책 상세 이동을 유지한다.

## Modal

- 독립 페이지와 같은 읽기 순서를 사용한다.
- 헤더에는 카드 유형을 중복 표시하지 않고 닫기 동작만 명확히 둔다.
- 본문만 스크롤되고 닫기 버튼과 책 상세 이동은 접근 가능한 상태를 유지한다.
- 중첩된 카드 표면과 캡슐 배지를 제거한다.

## Loading And Error States

- 로딩 화면은 카드 유형, 생각, 인용문, 책 메타 순서의 평평한 스켈레톤으로 표시한다.
- 독립 페이지와 모달에서 같은 데이터 상태를 사용한다.
- 잘못된 카드 ID 안내와 기존 `QueryError` 재시도 동작을 유지한다.

## Accessibility And Responsive Behavior

- 모달 제목은 스크린 리더에서 유지한다.
- 닫기와 책 상세 링크는 키보드로 접근 가능해야 한다.
- 긴 생각, 인용문, 책 제목은 모바일과 데스크톱에서 가로로 넘치지 않아야 한다.
- 모달은 최대 높이 안에서 본문을 스크롤할 수 있어야 한다.
- 라이트·다크 모드에서 본문과 구분선 대비를 유지한다.

## Verification

- `pnpm typecheck`
- 변경 파일 ESLint
- `pnpm build`
- 독립 페이지와 인터셉트 모달의 동일한 콘텐츠 순서 확인
- 인용문·카드 제목 유무에 따른 렌더링 확인
- 긴 본문과 모바일 폭 확인
- 라이트·다크 모드 확인
- 모달 닫기, 오류 재시도, 책 상세 이동 확인

## Out Of Scope

- 카드 수정 또는 삭제 기능 추가
- 책 상세의 카드 목록 개편
- 카드 API 또는 인증 흐름 변경
- 새로운 UI 라이브러리 추가
